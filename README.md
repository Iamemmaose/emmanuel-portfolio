# Emmanuel Ose — Frontend Developer Portfolio

A modern, responsive personal portfolio built to showcase my work, technical capabilities, and experience as a Frontend Developer.

The portfolio focuses on delivering a clean user experience, responsive layouts, reusable components, and performance-conscious frontend development.

**Live Website:** https://emmanuel-portfolio-pi-inky.vercel.app/

**Repository:** https://github.com/Iamemmaose/emmanuel-portfolio

---

## Overview

This portfolio is designed as a professional representation of my work as a Frontend Developer.

It showcases selected projects, technical skills, experience, and provides a way for potential clients, employers, and collaborators to learn more about my work.

The application was built with Next.js, React, and Tailwind CSS, with an emphasis on responsive design, component reusability, maintainable code, and a polished user experience.

## Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js
* npm
* Git

### Installation

Clone the repository:

```bash
git clone https://github.com/Iamemmaose/emmanuel-portfolio.git
```

Navigate into the project:

```bash
cd emmanuel-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the application in your browser:

```text
http://localhost:3000
```
